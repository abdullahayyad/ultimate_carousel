# ultimate_carousel

Every Flutter carousel transition in one package.

**[Try the live demo →](https://abdullahayyad.github.io/ultimate_carousel/)**

```dart
UltimateCarousel(
  effect: const CarouselEffect.cube(),
  loop: true,
  autoPlay: const CarouselAutoPlay(),
  children: slides,
)
```
